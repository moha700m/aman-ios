# أمان الغرفة / Aman Al-Ghurfa

Helper iOS room check for chalets, hotels and fitting rooms: magnetometer spikes, BLE tracker heuristics (AirTag / Tile / SmartTag / Google Find My), lens-glint assist, and checklists.

**Honest positioning:** فحص مساعد — not a guarantee, not professional gear.

- Bundle ID: `com.moha700m.aman`
- iOS 17+, Arabic + English
- Design: شاليه (sand + green)
- Remote content: https://moha700m.github.io/aman-ios/catalog.json

## Build
```bash
brew install xcodegen && xcodegen generate
open Aman.xcodeproj
```

## Privacy
No accounts, no analytics, no photo upload. See `docs/privacy.html`.
